# DataIntegrityChecker (다국어 데이터 정합성 검사 도구)

SQLite 데이터베이스에 저장된 다국어 텍스트 데이터를 분석하여, 특정 단어나 태그의 언어별 출현 빈도를 비교하고 결함을 탐지하는 품질 관리(QA) 자동화 도구입니다.

로컬라이제이션(Localization) 과정에서 발생할 수 있는 번역 누락, 중복 기입, 또는 제어 문자 태그의 유실 여부를 전수 조사하여 데이터 무결성을 보장합니다. 파이썬(Python) 기반으로 작성되었으며, 설정 파일(`config.ini`)을 통해 검사 규칙을 유연하게 변경할 수 있습니다.

## 주요 기능 및 프로세스

프로그램의 핵심 기능과 처리 흐름은 다음과 같습니다.

### 1. 환경 설정 로드 (Initialization)
검사 대상 DB 경로, 검색할 단어 목록, 언어별 컬럼 정보 등을 설정 파일에서 불러옵니다.

- **작동 원리**
    1. 프로그램 실행 시 `load_environment` 함수가 호출됩니다.
    2. 실행 경로에 `config.ini` 파일이 존재하는지 확인하고, 없다면 `create_default_config`를 통해 기본 템플릿을 생성합니다.
    3. 설정 파일이 있다면 `configparser`를 통해 DB 경로(`db_path`), 타겟 단어(`target_words`), 언어 컬럼(`language_columns`) 정보를 파싱하여 메모리에 적재합니다.

### 2. 데이터 추출 및 분석 (Extraction & Analysis)
DB에서 데이터를 조회하고 정규표현식을 활용하여 단어 빈도를 계산합니다.

- **작동 원리**
    1. `analyze_data` 함수가 SQLite DB에 연결하고 전체 데이터를 조회합니다.
    2. 조회된 각 레코드(행)에 대해 설정된 `target_words` 목록을 순회합니다.
    3. 각 언어별 텍스트에 대해 정규표현식(`re.findall`)을 사용하여 해당 단어가 몇 번 등장하는지 카운팅합니다. (특수문자 처리를 위해 `re.escape` 적용)
    4. 언어별 등장 횟수가 서로 다를 경우(예: 한국어 1회, 영어 0회), 해당 레코드를 불일치 항목으로 식별합니다.

### 3. 결과 리포트 생성 (Reporting)
분석된 불일치 내역을 파일로 저장하여 사용자가 검토할 수 있게 합니다.

- **작동 원리**
    1. `save_results` 함수가 분석 결과 리스트를 받습니다.
    2. Pandas 라이브러리를 사용하여 데이터를 표 형식(DataFrame)으로 정리합니다.
    3. DB 파일과 동일한 경로에 `result.txt` 파일을 생성하고 내용을 기록합니다.

## 핵심 로직: 분석 시퀀스

단어 빈도 불일치를 찾아내는 내부 로직의 순서는 다음과 같습니다.

1. **설정 확인**: `main` 함수 진입 시 `load_environment`를 호출하여 검사 규칙을 확정합니다.
2. **DB 연결**: `analyze_data` 내부에서 `sqlite3.connect`로 DB 세션을 엽니다.
3. **전수 조사**:
    - `SELECT` 쿼리로 테이블의 모든 데이터를 가져옵니다.
    - 이중 반복문(Row 순회 -> Target Word 순회)을 통해 정밀 검사를 수행합니다.
    - 각 언어 컬럼(`language_columns`)별로 단어 개수를 셉니다.
    - `set(counts.values())`의 길이가 1보다 크면(즉, 개수가 서로 다른 언어가 하나라도 있으면) 오류 목록에 추가합니다.
4. **결과 저장**: `save_results`에서 결과가 담긴 리스트를 텍스트 파일로 출력하고 프로그램을 종료합니다.
